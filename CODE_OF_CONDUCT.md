# Code of conduct

Git Receipts welcomes people with different backgrounds, identities, abilities, and levels of experience. Everyone participating in the project is expected to help keep it respectful and constructive.

## Expected behavior

- Be considerate and patient, especially with new contributors.
- Discuss ideas and code with specific, useful feedback.
- Respect different experiences, communication styles, and accessibility needs.
- Accept corrections, take responsibility for mistakes, and help resolve disagreements.
- Respect privacy and ask before sharing someone else's personal information.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized comments, unwanted advances, deliberate disruption, and sharing private information without consent are not acceptable. Repeatedly ignoring a request to stop is also unacceptable.

## Scope

This policy applies to project issues, pull requests, discussions, and other spaces maintained for Git Receipts. It also applies when someone explicitly represents the project in public.

## Reporting and enforcement

Report concerns privately to **[ihssmaheel@gmail.com](mailto:ihssmaheel@gmail.com)**. Include links, relevant context, and any immediate concerns. Reports will be handled as privately as practical; details may need to be shared with people necessary to investigate or respond.

Maintainers may remove harmful content, request a correction, issue a warning, temporarily restrict participation, or permanently exclude someone. The response will reflect the severity, impact, and any repeated behavior. Affected participants may contact the same address to provide additional context or request reconsideration.

Maintainers are expected to follow this policy too.
